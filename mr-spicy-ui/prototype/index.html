About

MR. SPICY is a neutral, premium control-panel UI reference: design system, EN/AR localization, RTL and accessibility. It is a standalone demonstration intended for legitimate software such as settings, developer or accessibility panels. It is not affiliated with, endorsed by, or connected to any game, and contains no gameplay or automation functionality.
