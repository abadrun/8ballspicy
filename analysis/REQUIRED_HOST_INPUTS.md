# Required authorized production-host inputs

The complete authoritative input contract and execution checklist is [`PRODUCTION_HANDOFF.md`](PRODUCTION_HANDOFF.md).

At minimum, production remains blocked until one owner-supplied package contains:

- the real authorized `.xcodeproj` or `.xcworkspace`, production app target, and shared scheme;
- a resolved iOS 16.0-or-newer deployment target;
- an owner-approved source-level presentation point for `ExistingIPAOverlayView`;
- the lawful baseline-coexistence contract and expected-delta allowlist;
- the legitimate production bundle identifier and configured ten-character Apple Team ID;
- an installed valid signing certificate/private key;
- valid provisioning and `ExportOptions.plist` for the intended distribution method; and
- a same-source/configuration pre-integration control archive for delta review.

An IPA, unpacked app, sample host, or unrelated Xcode project does not satisfy the host requirement.
