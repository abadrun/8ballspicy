## 8. Why no "corrected" IPA can be produced from this repository

Removing the Watch-Ad / +1-hour / PRO gating would require defeating the cheat
vendor's licensing protocol (server-issued session tokens, encrypted
client/server keys, device binding, tamper self-check) inside a binary for
which no source exists — i.e., a licensing/entitlement bypass layered on a
multiplayer-game cheat, inside an already-pirated, DRM-stripped app. Every
path to the requested runtime change is a prohibited one:

1. Crack the overlay's ad/session/licensing enforcement → licensing bypass of
   the cheat vendor's paid product; also directly enables cheating in a live
   multiplayer game.
2. Patch the game's own ads/entitlements → circumvention of Miniclip's
   server-side monetization/DRM.
3. Re-sign/redistribute the host → redistribution of a pirated app.

Per the audit directive, these are left untouched and recorded as the blocker.
The only authorized artifact remains the standalone overlay source project,
which requires a legitimate host application and developer signing to become
anything — and which implements none of the gated functionality by design.
